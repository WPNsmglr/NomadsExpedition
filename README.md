# Nomad’s Expedition
A mod for *The Long Dark* by Hinterland

<img width="2293" height="1203" alt="Alternative_Blueprints" src="https://github.com/Maple-Sapling/NomadsExpedition/blob/main/NomadsExpedition.png" />


## Status
- Work in progress (the sextant is not functional yet)

## About
A collection of accessories and tools designed for expeditions.

## Features
- Improvised Saw  
- Deer Hide Carrying Bag  
- Rabbit Hide Hip Bag  
- Sextant for cartography
- Carrying pack for snow shelters materials 

## Dependencies
- ModComponent  

Special thanks to the TLD Discord community!
